Wrench

One gateway for your team's coding agents

Wrench sits between opencode and OpenRouter. People sign in with GitLab, use the models their tier allows, stay within their budgets, and every request is recorded with its real cost.

Get started View on GitHub

Every model call takes one route

opencode 2.3

Unmodified. One device login; it holds only a Wrench key.

→

Wrench

Checks identity, tier and budget, forwards the request, records the attempt and confirms its cost.

→

OpenRouter

Only Wrench holds the key. No fallbacks, no retries, no model swaps.

What you get

GitLab sign-in

OIDC with PKCE and an email allowlist. Blocking an account in GitLab revokes its keys.

Model tiers

Each tier lists the models its people may use. The server enforces it on every request.

Budgets

Per-person and shared limits for 5 hours, a day, a week and a month, in exact decimals.

Real costs

Every attempt is journaled; unknown costs are confirmed from OpenRouter generation data.

Live dashboard

Budgets, usage, latency, sessions, keys and users, with alerts to Slack or Mattermost.

Simple to run

Four containers, configuration reloaded without a restart, encrypted backups to S3.

Try it in a minute

A demo with mocked GitLab and OpenRouter and 30 days of data. Needs Docker, Go 1.27 and Node 22.

git clone https://github.com/ordo-systems/wrench && cd wrench
make demo    # http://localhost:18080
opencode auth login opencode --method device --answer server=http://localhost:18080
