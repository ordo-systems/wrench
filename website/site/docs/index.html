Quick start

Wrench gives a team one route to coding-agent models. People sign in with GitLab, opencode talks only to Wrench, and Wrench enforces tiers and budgets before forwarding to OpenRouter.

Run the demo

The demo uses mocked GitLab and OpenRouter and 30 days of generated data. You need Docker, Go 1.27 and Node 22.

git clone https://github.com/ordo-systems/wrench && cd wrench
make demo

Open localhost:18080 and sign in by picking a user in the GitLab mock; user3@example.com is an administrator.

Connect opencode

opencode auth login opencode --method device --answer server=http://localhost:18080

Approve the code on the page opencode opens. Then /models lists the demo models.

Stop

make demo-down     # keep the data
make demo-reset    # delete the data
