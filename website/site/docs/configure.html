Configure

Policy lives in config/config.yaml: models, budgets, tiers, users and alerts. Secrets and runtime settings live in .env.

config.yaml

models:
  glm-5.3:
    upstream_id: z-ai/glm-5.3     # OpenRouter model ID
    reasoning_effort: low         # optional

budget:
  currency: USD
  timezone: UTC
  global_limits:                  # shared by everyone
    5_hours: 8.00
    day: 16.00
    week: 80.00
    month: 200.00
    warn_at_percent: [80, 95]

tiers:
  basic:
    default: true                 # exactly one default tier
    budget: {5_hours: 0.50, day: 1.00, week: 5.00, month: 20.00}
    models:
      - name: glm-5.3
        default: true             # exactly one default model per tier

users:                            # the allowlist, by verified GitLab email
  - email: ada@example.com
  - email: lin@example.com
    role: admin
    tier: basic

Rules

  • Edits apply without a restart. An invalid file is rejected whole, the old one keeps serving, and the config:invalid alert stays open until you fix it.
  • All four windows are required. 5_hours, day and week are fixed UTC windows; month is the calendar month. Zero means no access, not unlimited.
  • Requests check the user's tier budget and the global budget together. A spent window refuses with 402 until it resets.
  • Removing a user refuses their next request. Administrators are bound by the same budgets.
  • Token limits and prices come from OpenRouter's catalog, not from this file.

Alerts

Add an alerts section for low OpenRouter credit, error rate and slow first tokens; budget alerts follow warn_at_percent. Set WRENCH_ALERT_WEBHOOK_URL to a Slack or Mattermost incoming webhook, or read them on the dashboard.

.env

VariablePurpose
WRENCH_DOMAIN, WRENCH_PUBLIC_URLWhere Wrench is served
WRENCH_GITLAB_*GitLab URL, OIDC client, read_api token, check interval
WRENCH_OPENROUTER_KEYThe only upstream key; it never leaves Wrench
WRENCH_UPSTREAM_*Timeouts and concurrency limits
WRENCH_BACKUP_*Schedule, retention, restic password, S3

Changes to .env apply on docker compose up -d. Missing values stop startup.
